<h1 align="center">FFXIV 캐릭터 체격 그래프</h1>
링크: https://xiv-kaden.github.io/character-ratio-chart
<br>
<h2>설명</h2>
주변 캐릭터의 키와 몸무게를 축으로 표현한 그래프입니다. <br>
<br>
<h2>보는 방법</h2>
X축(가로)은 몸무게 선, Y축(세로)는 키 선입니다.<br>
위로 갈수록 키가 크고, 오른쪽으로 갈수록 무겁습니다.<br>
<br>
포인트의 오른쪽 이름이 겹칠 수 있으므로, ctrl + f 를 사용해<br>
본인 이름을 검색해 찾아 주셔도 좋습니다.
<br>
<br>
