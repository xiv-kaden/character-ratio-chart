## 설명
주변 캐릭터의 키와 몸무게를 축으로 표현한 그래프입니다. <br>
<br>

## 보는 방법
`X축(가로)`은 키(cm), `Y축(세로)`은 몸무게(kg) 입니다.<br>
위로 갈수록 키가 크고, 오른쪽으로 갈수록 무겁습니다.<br>
<br>
포인트의 오른쪽 이름이 겹칠 수 있으므로, `ctrl` + `F` 를 사용해<br>
본인 이름을 검색해 찾아 주셔도 좋습니다.
<br>
<br>
**09.06 추가**<br>
\- 이름이나 포인트에 마우스를 올릴 경우, 캐릭터 정보가 표시됩니다.<br>

**09.07 추가**<br>
\- 캐릭터 정보에 종족 및 부족, bmi 지수가 표시됩니다.<br>
※BMI 지수는 단순히 키와 몸무게 기준이므로, 근육량에 따라 비만이 아닐 수 있습니다.
